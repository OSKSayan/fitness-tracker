# Мой трекер — тренировки, питание, прогресс

Личное веб‑приложение на русском языке: план тренировок A/B и журнал, дневник питания и воды, шаги, вес и замеры с графиком и линией тренда, напоминания. Работает в браузере на телефоне и компьютере, без регистрации и сервера.

Полное ТЗ: [docs/SPEC.md](docs/SPEC.md).

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm run dev        # режим разработки: http://localhost:5173
npm run build      # проверка типов + сборка в dist/
npm run preview    # просмотр собранной версии: http://localhost:4173
```

Чтобы открыть с телефона в той же Wi‑Fi сети: `npm run dev -- --host` и откройте адрес «Network» из консоли.
Папку `dist/` после сборки можно разместить на любом статическом хостинге (GitHub Pages, Netlify и т. п.).

## Разделы

- **Главная** — последний вес, следующая тренировка, шаги, вода, калории и белок за сегодня, напоминания, быстрые кнопки.
- **Тренировки** — расписание (дни недели и дата старта настраиваются; отметки «выполнена», «пропущена», «перенесена»), редактор плана A/B, журнал с весом и повторами по подходам, самочувствием, заметкой и необязательным кардио. Первые две недели — режим лёгких весов; с третьей недели — подсказка «+2–5 кг», только если прошлая тренировка была комфортной и техника сохранялась.
- **Питание** — дневник с «примерной порцией», необязательными калориями и белком, учёт воды, редактируемые ориентиры и мягкие подсказки по привычкам.
- **Прогресс** — вес и замеры (талия, живот, грудь, бёдра), график с линией тренда и выбором периода, изменение с первой записи, средний темп за период, история с редактированием и удалением.
- **Настройки** — напоминания (тренировка, взвешивание, вода, дневник: время и дни), уведомления браузера, цели, единицы (кг/фунты, см/дюймы), экспорт/импорт JSON, демо‑режим, удаление данных.

## Где хранятся данные

В `localStorage` браузера на этом устройстве (ключ `fitness-tracker:data`). Никуда не отправляются. При очистке данных сайта они удаляются — делайте резервную копию: **Настройки → Экспорт в JSON**, восстановление — **Импорт из JSON**.
Демо‑режим хранит пример отдельно (`fitness-tracker:demo`) и не трогает ваш журнал.

## Напоминания

Срабатывают, пока вкладка с приложением открыта (в том числе в фоне): системным уведомлением, если браузер разрешил, и всегда — сообщением внутри приложения. Когда вкладка закрыта, уведомления не приходят — это ограничение браузерного приложения без сервера.

## Важно

Приложение — дневник для самоконтроля. Все цифры — ориентиры, а не медицинские предписания; оно не ставит диагнозы и не оценивает безопасность нагрузок. Возвращайтесь к тренировкам после больницы постепенно и по рекомендациям лечащего врача. При необычных симптомах или ухудшении самочувствия остановитесь и обратитесь за медицинской помощью.

## Стек

Vite + React 18 + TypeScript, без внешних UI‑ и chart‑библиотек (график — SVG).
