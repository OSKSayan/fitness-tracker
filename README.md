# Мой трекер — тренировки, питание, прогресс

Личное веб‑приложение на русском языке: тренировки A/B, еда и вода, шаги, вес и замеры с графиком, напоминания. Работает в браузере на телефоне и компьютере; по желанию — вход и хранение в облачной базе Supabase.

Полное ТЗ: [docs/SPEC.md](docs/SPEC.md).

## Открыть онлайн

https://osksayan.github.io/fitness-tracker/ — публикуется автоматически из ветки `main` через GitHub Actions. Это устанавливаемое приложение (PWA): иконка на главном экране, полный экран, работа без интернета. Android/Chrome: меню ⋮ → «Установить приложение». iPhone/Safari: «Поделиться» → «На экран „Домой“». Подсказка есть в приложении: **Настройки → Установить на телефон**.

Данные хранятся в браузере того устройства, где вы открыли приложение: телефон и компьютер не синхронизируются. Для переноса используйте экспорт/импорт JSON.

## Запуск локально

Нужен Node.js 18+.

```bash
npm install
npm run dev        # режим разработки: http://localhost:5173
npm run build      # проверка типов + сборка в dist/
npm run preview    # просмотр собранной версии: http://localhost:4173
```

Чтобы открыть с телефона в той же Wi‑Fi сети: `npm run dev -- --host` и откройте адрес «Network» из консоли.

## Разделы

- **Сегодня** — всё на один день: тренировка по плану (начать / перенести / пропустить), вода кнопкой «+ стакан», еда, шаги и вес. Стрелками можно листать прошлые дни.
- **Тренировки** — большая кнопка «Записать тренировку», дальше по плану, история. Поля подсказывают прошлые веса, есть кнопка «как в прошлый раз». Первые 2 недели — режим лёгких весов; с 3-й недели — подсказка «+2–5 кг», только если прошлая тренировка была комфортной.
- **Прогресс** — текущий вес, изменение с начала, график с линией тренда, замеры, история записей.
- **Настройки** — аккаунт и облако, дни тренировок и упражнения, напоминания, ориентиры, единицы, резервная копия, демо-режим.

## Где хранятся данные

- **Без входа** — в `localStorage` браузера на этом устройстве.
- **С входом (Supabase)** — в облачной базе PostgreSQL, таблица `fitness_data` (одна строка jsonb на пользователя). Браузер остаётся локальной копией: приложение работает без сети и досылает изменения, когда сеть появится. Телефон и компьютер с одним аккаунтом видят одни и те же данные.
- Резервная копия: **Настройки → Резервная копия → Скачать копию** (JSON).

### Подключение Supabase

1. Создайте проект на [supabase.com](https://supabase.com).
2. **SQL Editor → New query** → вставьте [supabase/schema.sql](supabase/schema.sql) → **Run**.
3. **Authentication → URL Configuration → Site URL**: `https://osksayan.github.io/fitness-tracker/`. Чтобы не подтверждать email, можно выключить **Authentication → Providers → Email → Confirm email**.
4. Впишите **Project URL** и ключ **anon public** в файл `.env` (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`). Это публичные значения; ключ `service_role` и пароль базы в код не добавляйте.
5. Для просмотра в pgAdmin: Supabase → **Connect** → строка подключения (host, port, user, пароль базы). Удобные представления: `v_weight`, `v_workouts`, `v_food`.

## Напоминания

Срабатывают, пока вкладка с приложением открыта (в том числе в фоне): системным уведомлением, если браузер разрешил, и всегда — сообщением внутри приложения. Когда вкладка закрыта, уведомления не приходят — это ограничение браузерного приложения без сервера.

## Важно

Приложение — дневник для самоконтроля. Все цифры — ориентиры, а не медицинские предписания; оно не ставит диагнозы и не оценивает безопасность нагрузок. Возвращайтесь к тренировкам после больницы постепенно и по рекомендациям лечащего врача. При необычных симптомах или ухудшении самочувствия остановитесь и обратитесь за медицинской помощью.

## Стек

Vite + React 18 + TypeScript, Supabase (PostgreSQL + Auth). График — SVG без библиотек.
